문제4. 일반 Prompt와 CO-STAR Prompt 비교
------------------------------------------------------------
상황:

한 교육센터의 최근 변화:
- 수강생 수: 95명 → 148명
- 질문 대기시간: 6분 → 16분
- 장비 장애 신고: 월 5건 → 14건
- 과제 미제출률: 7% → 13%
- 만족도: 4.7점 → 4.0점

문제:
A. 일반 Prompt
B. CO-STAR Prompt

두 개를 만들어 같은 데이터로 실행한다.

CO-STAR 조건:
C: 교육센터의 최근 운영 변화
O: 가장 시급한 문제와 우선 조치를 판단
S: 운영 보고서
T: 객관적, 과장 금지
A: 센터장
R:
[핵심 지표]
[가장 시급한 문제]
[근거]
[우선 조치 2개]
[3문장 요약]

마지막에 두 응답을 모두 출력한다.

문제5. Thinking Level 비교 + 실행시간
------------------------------------------------------------
상황:

교육센터가 아래 세 개선안 중 하나를 먼저 선택하려 한다.

A. PC 15대 추가 구매
B. 질문 대응 강사 1명 추가
C. 과제 알림 시스템 도입

현재 정보:
- 좌석 부족은 없음
- 질문 대기시간은 6분에서 16분으로 증가
- 장비 장애 신고는 5건에서 14건으로 증가
- 과제 미제출률은 7%에서 13%로 증가
- 만족도는 4.7점에서 4.0점으로 하락

요구사항:
1. run_gemini(thinking_level: str) 함수 작성
2. time.perf_counter()로 실행시간 측정
3. low / medium / high 실행
4. 각 실행에서
   - 답변
   - 응답시간
   - Thought Token
   - Total Token
   출력
5. 마지막에 세 결과를 한 번 더 요약 출력

문제7. TXT 파일 하나 업로드 - 대량 로그 분석
------------------------------------------------------------
사용 파일:
data/support_case_log.txt

파일에는 240개의 CASE가 있다.

요구사항:
1. 파일 하나만 업로드한다.
2. Gemini에게 다음 분석을 요청한다.

- 가장 자주 나타나는 TYPE 후보 3개
- HIGH LEVEL 사례에서 눈에 띄는 특징
- RESPONSE_MIN이 큰 CASE 예시 5개
- REPEAT 값이 큰 CASE 예시
- 아직 OPEN인 사례에서 확인할 점
- 데이터만으로 원인이라고 단정할 수 없는 내용

3. 답변에서 CASE 번호를 근거로 사용하도록 Prompt를 작성한다.
4. 파일의 모든 CASE를 임의로 다시 만들어내지 않도록 지시한다.
5. 결과 출력 후 파일 삭제

주의:
이 실습에서도 Python으로 TXT 내용을 직접 읽어서 분석하지 않는다.

문제10. 표 이미지 하나 + Structured Output
------------------------------------------------------------
사용 파일:
data/class_operation_board.png

Pydantic 모델:

ClassRow
- no: int
- room: str
- time: str
- subject: str
- status: str

ClassBoard
- document_title: str
- rows: list[ClassRow]
- check_count: int
- hold_count: int

요구사항:
1. 표 이미지 하나 업로드
2. response_format에 ClassBoard.model_json_schema() 전달
3. 18개 행을 모두 추출
4. 원본 JSON 출력
5. ClassBoard.model_validate_json()으로 검증
6. 각 행 출력
7. Python 코드에서 실제 rows의 STATUS를 세어
   CHECK 개수와 HOLD 개수를 계산
8. Gemini가 반환한 check_count / hold_count와
   Python 계산값을 비교 출력

중요:
- 별도 JSON 파일을 읽지 않는다.
- 표 이미지 하나만 사용한다.
- 다른 행의 값을 섞지 않는다.
